# Уникальные входные IP подписки

В карточке пользователя админ видит число **различных публичных исходных IP прямого VLESS** на активных локациях подписки (включая скрытые локации с действующим доступом). Это наблюдение, не глобальный лимит. Профиль подписки и её устройства объединяются по subscription ID. Считается объединение множеств, а не сумма по нодам; один IP у двух разных подписок учитывается у каждой независимо. IP выхода VPS/WARP к этому счётчику отношения не имеет.

Источник — текущие online maps штатного Xray. Берётся последний принятый снимок каждой ноды; новый пустой снимок заменяет непустой. Окно свежести — 90 секунд по времени замера и приёма. Это не атомарное фото всей сети: переход с Wi-Fi на LTE может кратко дать два IP; устройства за одним NAT дадут один, а IPv4 и нативный IPv6 — два. IPv4-mapped IPv6 нормализуется в IPv4. Свежесть нод требует синхронизированных часов. Неполный охват показывается явно, а без пригодных данных число не выводится.

CDN-идентификаторы, IP прокси CDN, непубличные адреса и чужие служебные профили не учитываются. Hy2 `/online` даёт количество соединений, а не множество клиентских IP: его нельзя прибавлять. Нулевое число для прямого VLESS не означает отсутствие подключений через CDN/Hy2. Действующий локальный connlimit не переводится на новый счётчик; глобальных блокировок, киков и изменений подписок нет.

## Включение (для отдельного согласованного rollout)

Сначала обновить контрольный сервис/бот и совместимые pull-агенты. Сбор опциональный: для участвующих узлов безопасно подготовить один и тот же **отдельный случайный 32-байтный секрет**, записанный 64 шестнадцатеричными символами в `/data/node-control/subscription-ip-hmac.key` (0600, доступ агенту). Не использовать ключи WARP/UUID/token/SSH, не передавать через Telegram и не коммитить. Перезапуск Xray для ключа не нужен. Без файла или при ошибке опроса стандартная телеметрия продолжает работу без поля `subscription_ips_v1`. Старые и push-ноды не дают данных этому счётчику. При разных ключах свежих нод результат недоступен до согласования ключей. Для отключения сбора удалить только этот файл. Устаревшие данные перестанут участвовать в пределах окна свежести.

В существующей node telemetry по mTLS передаются не адреса, а 128-битные HMAC-метки, зависящие от подписки. Бот хранит последний снимок ноды, не создаёт историю IP и не показывает сами метки. Метки остаются псевдонимными данными; ограничивать доступ к БД и резервным копиям. Сбор ограничен по времени, числу запросов и размеру; отказ от необязательного измерения не означает «никого онлайн». Развёртывание проверять по охвату локаций, не используя счётчик для санкций.
